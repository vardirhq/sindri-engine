# Sindri Game Dev

Sindri Game Dev is a free plugin by **Vardir** for developing games with
Sindri Engine. Intended availability is all countries where the host platform
makes the plugin available. Public directory publication is pending.

## What it helps with

- Build and extend 2D and 3D games using Decay scripts, scenes and prefabs.
- Create responsive HUDs and menus with Weave.
- Look up exact APIs, component fields, examples and known limitations.
- Diagnose project errors and prepare native playtests or web exports.

The plugin bundles Sindri's fifteen-document knowledge pack. It instructs the
assistant to verify APIs, inspect the project's actual version, and distinguish
static checks from compilation and playtesting. Sindri is pre-alpha; project
source takes precedence when the bundled snapshot is older.

## Getting started

Select Sindri Game Dev in your host's plugin picker when available, then provide
your project files or repository and describe the game or change you want.
For example: “Build a small Sindri platformer with a restartable level” or
“Explain and fix these Decay checker errors.”

The plugin supplies instructions and references. It does not bundle the engine,
compiler, hosting or an independent repository connection. Running a checker,
editing a repository or playing a game requires those tools to be available in
the host environment. Vardir charges no plugin fee; host subscriptions and
third-party services may have their own charges.

The [downloadable knowledge pack](../../knowledge-pack/) can also be used with
other chat tools. See the [engine repository](https://github.com/vardirhq/sindri-engine)
for engine installation and licensing.
