# Sindri Game Dev support

Sindri Game Dev is maintained by **Vardir** and provided free of charge.

## Report a bug or request a feature

Open an issue in the
[Sindri Engine issue tracker](https://github.com/vardirhq/sindri-engine/issues).
Include “Sindri Game Dev plugin” in the title so it can be distinguished from
an engine issue. A GitHub account is required to submit an issue.

Include the plugin version if available, your engine revision, the relevant
error message, steps to reproduce, and a small example. State whether the
problem occurs in the editor, native player, browser, or assistant response.

GitHub issues are public. Remove secrets, personal information and private
project content before posting. Share only material you have permission to share.

## Private questions

Email [chris@vardir.no](mailto:chris@vardir.no) for private support or privacy
questions. Do not send passwords, API keys or access tokens.
Support is provided as availability permits; there is no guaranteed response time.

For account, billing or host-platform problems, contact the host provider.
