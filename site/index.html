How you build

An editor, a language and a UI system, made together.

Games are authored in the editor, Decay and Weave. Rust is what the engine is written in, not something you need to write a game. Native and browser builds share one runtime, one scene format and one renderer.

ED

Editor

A native editor working on the same world the game runs: hierarchy, inspector, asset browser, sprite slicing, a Timeline, undo, and Play, Pause and Stop on the real engine.

DC

Decay

A statically typed gameplay language. Game state, events, input, physics, spawning, audio and UI live in Decay scripts, checked before they run.

WV

Weave

Responsive presentation for game UI. Styles and layout rules recompose one interface for a desktop, a phone held upright and a phone on its side.

RS

Engine

2D and 3D in one scene model: sprites, tilemaps, voxels, lit GLB models and shadows, Rapier physics, audio buses and gamepads, built on wgpu.

Captured by a binary in the repository rather than a screen grab, so it can be retaken after every change.

Decay

A gameplay language that refuses to guess.

Decay is Rust-inspired and statically typed, without ownership, lifetimes or unsafe. A misspelled host member, a wrong event payload or a mismatched type is a diagnostic with a source location, not a mystery at runtime.

  • @export fields show up in the editor without running the script
  • Typed events, messages, shared state and script references
  • Vec2, Vec3, arrays, maps and bounded loops
  • A language server with completion, hover and diagnostics

Honest about the gaps

Some large pieces don't exist yet, and Sindri doesn't pretend they do.

Skeletal animation and animation state machines
A Decay debugger, formatter and coroutines
Navmesh navigation and steering
Scene streaming and texture compression
Spatial audio
Accessibility labels in game UI

Each gap has a row in the parity table, set against what an engine is expected to do. Working code beats plausible architecture: it makes progress slower than ticking boxes on a roadmap, and it makes the boxes mean something.
